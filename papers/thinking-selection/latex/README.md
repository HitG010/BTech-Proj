# Reviewer LaTeX package

This is the LaTeX presentation of manuscript v0.2 at `f2c5b6e`.
The layout was prepared on 27 October 2026. It is an internal review draft;
author endorsement, names, affiliations, and declarations remain pending.

## Files

- `main.tex`: editable manuscript with equations, tables, captions, and citations.
- `references.bib`: unchanged copy of the existing bibliography.
- `figures/`: unchanged copies of the three approved vector PDF figures.
- `output/pdf/main.pdf`: compiled review copy.
- `source-records/`: the 13 project documents identified in Appendix D.
- `source-manifest.json`: original document and figure hashes.
- `layout-review.json`: build and presentation review record.

## Build locally

Use a TeX distribution with pdfLaTeX, BibTeX, and latexmk. From this directory:

```sh
latexmk -pdf -interaction=nonstopmode -halt-on-error -outdir=output/pdf main.tex
```

Alternatively, run `make`. The output is `output/pdf/main.pdf`.
No model, experiment environment, Python installation, or network access is
needed for the build once the standard TeX packages are installed.

## Use in Overleaf

Upload `thinking-selection-review-source.zip` as a new project. Select
`main.tex` as the main document and pdfLaTeX as the compiler. The archive has
its own figures and bibliography; it does not require access to this repository.
No file has been uploaded or sent to a reviewer by this task.

## Presentation choices

- A4, single column, 11-point type, numbered lines, and page numbers.
- Scientific wording, numerical rows, and figure captions retain manuscript v0.2.
- Original table and section labels remain explicit, including Box 1 and Table C1.
- Literature links become numbered citations generated by BibTeX. Only the 13
  cited bibliography entries print; the full existing `.bib` file is supplied.
- Project document links become source identifiers. New Appendix D lists their
  paths. The identified Markdown records are bundled for inspection; links
  within those records can still require the full repository.
- The Markdown-only figure download links and reference-navigation paragraph
  are omitted. No scientific result or interval is recomputed.
- The figure PDFs are embedded unchanged. This is a manuscript layout export,
  not a new export of the frozen scientific plots.

The undated MiniLM model card retains its original missing year in the BibTeX
file. BibTeX reports one `empty year` warning for that entry. The reference
prints its existing undated/access-date note; no publication year is invented.

The source records are documentation snapshots. They do not include raw
responses, score caches, training references, model weights, or sealed outcomes.
This local review bundle does not constitute a public artifact release.

## Editing

Edit `main.tex` directly for LaTeX changes. Keep scientific edits synchronized
with `../manuscript.md` through a separate reviewed change. The Markdown source
was not modified during this conversion. Author information can be supplied in
`\author{...}` when available; the current placeholder does not imply anonymity
or compliance with any specific venue's submission rules.
